# 玄枰五子棋

一个可离线运行的精美 3D 五子棋网页游戏。使用 React、TypeScript、Three.js 与 Vite 构建，棋盘、木纹、青瓷和星穹材质均由程序生成，无外部图片或音频资源。

## 已实现功能

- **三种对局模式**
  - 本地人机：1–100 级连续难度，AI 在 Web Worker 中运行，不阻塞棋盘交互。
  - 同页双人：两名玩家轮流操作，也可自我对弈。
  - AI 大模型：配置 OpenAI 兼容的 `/chat/completions` 接口、模型和 API Key。
- **三套胜负／禁手规则**
  - 自由五子棋：双方五连或长连获胜，无禁手。
  - 标准五子棋：双方恰好五连获胜，长连不获胜，无禁手。
  - 连珠：黑棋恰好五连获胜，三三、四四、长连为禁手；白棋无禁手，五连或长连获胜。禁手检测包含假三递归判断，且恰好五连优先。
- **Swap2 交换开局**：可叠加到任意胜负规则。支持三手后持白／交换／再摆两手，以及五指局面交还先手选色；选色后白棋继续。AI 使用本地局面评估完成交换决策。
- **四套视觉主题**：胡桃雅木、玄墨素瓷、雨过天青、星穹夜弈。
- **完整对局体验**：旋转与缩放、俯视、落子动画、接触阴影、合成音效、禁手点提示、悔棋、暂停、认输、重开、胜负结果、逐手棋谱回看。
- **响应式布局**：桌面与手机竖屏自动适配镜头距离。

## 运行

要求 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 大模型配置

在首页选择「大模型」，填写：

1. 接口地址，例如服务商提供的 `https://…/v1`；
2. 服务商支持的模型 ID；
3. API Key；
4. 思考强度与模型参数 JSON。默认输出预算为 4096 tokens，低／中／高思考强度映射为 `reasoning_effort`，默认不发送该字段。

模型参数可配置 `max_tokens`、`temperature` 等；将一项设为 `null` 会从请求中删除它。若服务商要求 `max_completion_tokens`，可替换默认的 `max_tokens`。推理模型因输出长度不足而未返回落子时，界面会给出提高输出预算或降低思考强度的提示。

浏览器直接请求你配置的服务商，因此服务商必须允许浏览器 CORS。密钥仅保存在当前标签页的 `sessionStorage`，不会写入仓库，也不会经过本游戏服务器。大模型返回的坐标会由本地棋规再次校验；非法坐标会要求模型重答一次，连续失败后可手动重试。未配置接口时，本地人机和双人模式仍可完整使用。

## 操作

- 点击棋盘交叉点：落子。
- 拖动：旋转视角；滚轮／双指：缩放。
- `Space`：从首页快速开局。
- `Esc`：暂停／继续。
- `M`：静音切换。
- `Ctrl / ⌘ + Z`：悔棋。

## 测试与验收

```bash
npm run check          # TypeScript
npm test               # 棋规、Swap2、AI、大模型解析单元测试
npm run build
npm run verify         # 基础 Three.js 渲染／开始／暂停检查
npm run verify:gomoku  # 完整浏览器交互回归
```

浏览器脚本默认使用 `/usr/bin/chromium`，也可通过 `CHROMIUM_PATH` 指定浏览器。完整回归覆盖主题、Swap2 全部分支、悔棋、胜利、重开、暂停、100 级 AI 实际应手、模拟大模型接口和移动端。大模型测试使用确定性的本地 mock，不消耗真实 API 额度。

## 代码结构

- `src/game/rules.ts`：棋盘、胜负、禁手与合法落点。
- `src/game/opening.ts`：纯函数 Swap2 状态机。
- `src/game/ai-core.ts`：候选点评分、迭代加深 Alpha-Beta、100 级参数映射。
- `src/game/ai.worker.ts`：后台 AI 计算。
- `src/game/llm.ts`：大模型提示词、请求、解析与合法校验。
- `src/game/controller.ts`：完整对局状态与交互编排。
- `src/game/scene.ts`：Three.js 实例化棋盘渲染、镜头和视觉反馈。
- `src/pages/Home.tsx`：设置、HUD、棋谱与结果界面。

## 数据与限制

- 这是**前端单页游戏**，人与人对战采用同页操作，不包含联网房间。
- 设置保存在当前浏览器 `localStorage`，不会跨设备同步；清除浏览器数据会丢失设置。棋谱只保留在当前对局，不做云端持久化。
- 连珠禁手用于休闲自动裁决，不包含竞赛中的认禁手势、计时或完整赛事管理系统。
- 真实 GPU 帧率取决于设备。仓库浏览器回归同时记录 draw call、三角形数和渲染器信息，软件 WebGL 的帧率不作为硬件性能成绩。
